EMBER · flash a swarm node

Firmware __FW_VERSION__ · XIAO ESP32-S3 Sense · one image for every board (node or gateway)
1. Install the firmware
  1. Use Chrome or Edge on a laptop (Safari and Firefox can't talk to USB devices).
  2. Plug the XIAO in with a USB-C data cable.
  3. Click the button below, choose the port (e.g. USB JTAG/serial debug unit or cu.usbmodem…), then Install.
This browser can't flash devices. Open this page in Chrome or Edge. Flashing needs a secure (https) page.

Port doesn't appear, or the install fails to connect? Hold the tiny B (BOOT) button, tap R (RESET), release B, and try again. "Erase device" wipes the saved node id, so you'll need to set it again in step 2.

2. Set it up and test it
  1. Open the EMBER serial console, click Connect, and pick the same port.
  2. Give the board its identity: CFG|id=1 (2, 3, … for the next boards) or CFG|role=gateway. It reboots.
  3. Click Self-test. You want LOG|selftest PASS.
  4. Within 30 s you'll see heartbeats like RX|1|0|0|H|n1|s1|up5|hz4|snd5.
3. Use it with the command center

Close the console tab first (only one program can use the port). Then on the laptop:

python -m gateway.server --serial /dev/cu.usbmodemXXXX --nodes config/nodes-single.json --sim quiet --auto

A single node plugged in over USB works as its own gateway. Full guide: docs/SETUP_GUIDE.md
